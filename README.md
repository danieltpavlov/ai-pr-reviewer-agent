# 🤖 AI Pull Request Reviewer Agent

Автономен AI агент, изграден с **Python**, **Google Gemini API** и **PyGithub**, който автоматизира прегледа на код (Code Review) в GitHub. Агентът извлича разликите (Diff) от отворени Pull Requests, анализира ги за сигурност, качество и добри практики, и автоматично публикува структуриран отчет като коментар.

---

## 🌟 Основни функции

- 🔍 **Автоматично извличане на промени**: Чете заглавието, описанието и променените файлове от всеки избран Pull Request чрез GitHub REST API.
- 🧠 **AI Анализ с Gemini**: Използва най-новия модел `gemini-3.6-flash` за прецизен и бърз преглед!
- 🔒 **Фокус върху сигурността**: Проверява за изтекли тайни (API ключове, пароли), логически уязвимости и потенциални рискове.
- 💬 **Директна обратна връзка**: Публикува форматиран в Markdown отчет директно в дискусията на съответния Pull Request.
